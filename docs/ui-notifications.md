# 状態・通知の表示

ファイル表示の下部に固定ステータスバーは設けません。ツリー・一覧に縦幅を割り当てます。

- スキャン中のステップ・進捗は対象ドライブのカードに表示します。件数、経過時間、再試行、メモリ上限などの詳細は同じ表示のツールチップにまとめます。
- 完了・キャンセルはドライブ名を含む右下のトーストで通知し、6秒後に閉じます。手動でも閉じられます。通知表示中だけタイマーを使い、バックグラウンド監視は行いません。
- エラー・警告は右下に表示し、手動で閉じるまで残します。別ドライブの完了など一時的な通知で上書きしません。
- スキャン日時・処理時間・管理領域の未解決数はドライブカードと履歴選択のツールチップに表示します。履歴を切り替えた場合、履歴選択の説明は実際に表示中のスキャンを示します。
- サイズの集計方針は比較欄の情報アイコン、保持規則は履歴選択のツールチップから確認できます。
- 未スキャンの場合は一覧領域に開始方法を表示します。差分の実際の比較期間は常時表示を維持します。

合成データのUIスモークテストで通常表示・履歴切り替え・比較・複数ドライブの進捗と、通知の自動消去、手動消去、エラーの保持を検証します。実ディスクの書き込みや実履歴の削除は行いません。

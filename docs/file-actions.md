# ファイル操作

## 開く・コピー

ツリーと一覧の右クリックメニューの先頭に「開く」を置きます。フォルダーはエクスプローラーで、ファイルは関連付けられたアプリで開きます。ファイルはダブルクリックでも開けます。一覧でフォルダーをダブルクリックしたときは、アプリ内でその階層に移動します。

パスのコピーはツリーと一覧から使え、ファイルの場合は親フォルダーのパスとファイルのパスを選べます。履歴に記録されたパスが、今も存在するとは限りません。存在しない、アクセスが拒否された、関連付けに失敗したといった場合はトーストで通知し、アクセス拒否を「存在しない」とは断定しません。

## ごみ箱への移動

ファイルと容量分析の一覧の右端に、ごみ箱のボタンを置きます。押すと今の対象を読み取って確かめ、同じ項目が存在する場合だけ確認ダイアログを表示します。フォルダーの場合は、配下も対象になることをダイアログで示します。存在しない場合はダイアログを出さず、トーストで通知します。

確認ダイアログでは、Enter キーで実行されないようにし、キャンセルボタンは通常の色にします。処理中は、同じ操作を重ねて実行できないようにします。スキャンが読み取り専用であることと、この明示的な操作でファイルを書き換えることは、区別して扱います。

## 保護対象

- システム属性の項目にはボタンを出さず、実行時にも拒否する。
- 各ドライブの `Windows` とその配下、および Windows API が返す実際の Windows ディレクトリと配下を保護する。
- ルート直下の `Program Files`、`Program Files (x86)`、`ProgramData`、`Users`、`Documents and Settings`、`System Volume Information`、`$Recycle.Bin`、`Recovery`、`PerfLogs` 自体を保護する。
- プロファイル直下のコンテナと、Windows の既知の特別なフォルダー自体も保護する。Windows 以外の全配下を一律禁止にはしない。
- 隠し属性だけなら許可するが、強い警告を表示する。確認したあとに隠し属性が付いた場合は、もう一度確認を求める。システム属性も付いている場合は、禁止を優先する。

保護するパスの正確な判定は、[`FileRecyclePolicy`](../src/Something.Windows/FileRecyclePolicy.cs) を正とします。保存済みの属性でボタンの有無を決めるだけでなく、確認と実行の各段階で、現在の属性を検証し直します。

## 識別とパス検証

[`FileRecycleWorkflow`](../src/Something.Application/FileRecycleWorkflow.cs) は、ボリューム GUID に対応する履歴キー、シリアル、MFT 番号とシーケンス、項目の種別を照合します。ドライブ文字と名前だけを頼りに実行することはしません。確認の前、確認のあと、Shell 操作の直前に検証し、別の項目に置き換わっていれば中止します。

相対・UNC・デバイスパス、代替ストリーム、ワイルドカード、`.` / `..`、末尾ドット・空白、予約デバイス名、NTFS 予約レコードを拒否します。親ディレクトリは再解析ポイントをたどらずに確認し、削除を許可しない共有モードで読み取りハンドルを開いたままにします。ジャンクションなどを経由するパスは操作しません。

## Shell と結果

専用 STA スレッドの `IFileOperation` を使用し、`FOFX_RECYCLEONDELETE` と `FOFX_ADDUNDORECORD` を指定します。ごみ箱への移動以外の削除になると示された場合は中止し、完全に削除する処理に切り替えることはしません。成功したかどうかは、HRESULT と中止状態だけでなく、コールバックで受け取ったごみ箱内の項目でも確認します。

移動に成功した名前と、すでに存在しないと確認した名前は、取り消し線で表示します。ハードリンクのほかの名前は別に扱い、フォルダーの場合は配下にも反映します。この状態はメモリ内だけで共有し、再スキャンや終了時に破棄します。元の履歴・集計値・キャッシュの容量は書き換えず、削除後の実際の使用量は次のスキャンで確認します。

識別の確認と Shell のパス操作は、一体のトランザクションではありません。フォルダーの操作の途中で失敗した場合、すでに移動した中身が自動で元に戻るとは限りません。結果が不明な場合に、全体の成功として表示することはしません。

通常のテストでは偽のバックエンドを使います。実際の Shell を使うテストは、[テスト](testing.md)を参照してください。

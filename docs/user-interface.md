# 画面と状態管理

## ドライブとタブ

上部のドライブカードは総容量・使用量・空き容量とスキャン状態を表示します。完了後は最終スキャン日時を表示し、秒単位の日時・処理時間・件数はツールチップで確認できます。カードは横方向へスクロールし、選択状態はアウトラインで示します。カード内のスキャンアイコンは対象ドライブだけを操作し、非選択ドライブをスキャンしても選択を変更しません。

| タブ | 内容 |
| --- | --- |
| ファイル | ツリーで選んだフォルダの直下のファイル・フォルダ |
| 容量分析 | ツリーで選んだフォルダ以下を横断した容量一覧。既定はフォルダのみで、ファイルを含めることも可能 |
| DB 管理 | 選択ドライブのスキャン履歴、範囲選択、削除、DB 全体の最適化 |

一覧はヘッダークリックで列ソートし、連続スクロールで追加読み込みします。DB 側はページ単位で取得し、表示件数を固定の上位件数に限定しません。戻る・進むは閲覧履歴、上へは親フォルダへの移動です。深いツリーでは選択項目が見えるよう横スクロールを調整します。

## 表示するスキャンと比較

比較モードの切り替えを左に置き、その隣に比較元と比較先のスキャンを表示します。日付の選択はモーダルから、スキャンの存在する日付と一覧を確認して行います。比較中も通常のサイズ列を維持し、一覧には増減を追加します。

ツリーは数値を追加せず、展開アイコンと名前の間に増加・減少・比較不能の印を置きます。色だけに依存せず、形とツールチップでも状態を示します。比較期間と欠測の意味は[履歴の仕様](history.md)を参照してください。

## 属性と表示設定

設定画面の「システムフォルダ・ファイルを含める」「隠しフォルダ・ファイルを含める」は既定で両方オンです。ドライブ共通の値を `%LOCALAPPDATA%\Something\display-settings.json` へ保存します。スキャンや DB 保存の対象は減らしません。

ファイルと容量分析の一覧は、テーマに合わせたファイル／フォルダアイコンを使用します。Hidden は斜線付きの目、System は盾を重ね、ツールチップと読み上げにも含めます。属性不明は通常と断定しません。

## 切り替えとキャッシュ

ドライブ・世代・比較条件の切り替えでは、古い表示を操作中に部分的に差し替えません。待機状態にして新しいツリー・一覧・パス・件数をまとめて反映します。新しい要求が来た場合は、古い完了結果で画面を上書きしません。

`ScanSession` は同じ世代の表示設定別集計をメモリに保持します。除外のない場合は保存済み集計を使い、残りの設定は初回に計算した完全な結果を再利用します。全ファイルのストリームモデルをキャッシュする方式ではありません。ルート一覧の先頭ページも再利用し、通常フォルダの一覧キャッシュは直近一フォルダを基本とします。

ドライブ間でセッションは別ですが、保持している各ドライブへ戻る場合はそのキャッシュを利用します。世代の差し替え・履歴を閉じる・DB 管理のための解放・終了時に破棄します。キャッシュは DB や設定 JSON に書き戻さず、キャンセルした不完全な結果も保存しません。

## 待機表示

| 操作 | 表示 |
| --- | --- |
| ドライブ・世代・比較条件の切り替え | 全体の読み込みアニメーション |
| ツリーの展開 | 300 ms 以上かかる場合だけ対象行に小さなスピナー |
| フォルダ移動・一覧更新・容量分析の条件変更 | 300 ms 以上で対象領域に読み込みアニメーション |
| 選択ドライブの取得 | ディスクから DB へ運ぶクレーンのアニメーションと進捗 |
| 履歴削除・DB 最適化 | それぞれ専用のアニメーション |
| 非選択ドライブのスキャン | カードの進捗のみ。中央表示は変更しない |

読み込み切り替えはスキャン表示より優先します。すべてのアニメーション（読み込み・スキャン・履歴削除・最適化・起動）は同じ時間規則に従います。

| 規則 | 値 | 目的 |
| --- | ---: | --- |
| 表示開始までの遅延 | 300 ms | これより早く終わる処理では何も表示しない |
| 表示後の最低表示時間 | 500 ms | 一瞬だけ表示されるちらつきを避ける |
| 終了時のフェードアウト | 200 ms | 周回の途中で終えても途切れて見せない |

処理が終わったら、最低表示時間を満たした時点で周回の途中でもフェードアウトします。周回の終端までは待ちません。全体の読み込みでは、途中の表示を見せないため画面は直ちに覆い、キャラクターと説明文だけを遅延後に表示します。領域内の読み込みは領域側の 300 ms の遅延で覆い始め、アニメーション側では重ねて遅延しません。モードの切り替えは周回の終端で行います。Windows のアニメーション無効設定では、同じ遅延と最低表示時間で静止表示とし、フェードは行いません。取り消しや終了時は即時停止します。

図形は共通の `ChickFigure`、XAML のベクター、Storyboard で構成します。動画ファイルは使いません。読み込み・スキャン・履歴削除・最適化で同じキャラクターを共有し、各モードの姿勢と表示物をリセットします。笛と文字は視覚表現で、音は鳴らしません。単体確認は `run-animation-preview.bat` です。

## 通知と起動

完了・情報はアクセント色を基準としたトースト、警告・エラーは意味別の色とアイコンで通知します。全種類をタイトルと本文の二行構成にし、成功・情報は時間経過で閉じ、警告・エラーは閉じる操作まで保持します。背景は不透明です。操作対象が存在しない場合もトーストを使います。

起動時はスプラッシュで初期化を示し、ドライブカードの履歴状態をそろえてから最初のファイル表示へ進みます。起動時に自動スキャンや日次整理は行いません。

単一起動は Windows App SDK の `AppInstance` を使い、ユーザーとログオンセッションごとに登録します。二回目は既存ウィンドウを表示・復元し、応答不能時に別 DB インスタンスを開きません。デモとアニメーションプレビューは通常版と別のキーを使います。

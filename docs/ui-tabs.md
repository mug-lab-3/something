# タブ表示

「ファイル／DB管理」と「フォルダ内／ランキング」は共通の下線スタイルを使います。選択中はアクセント色の3 DIPの下線と太字、未選択は控えめな文字色です。ホバー・押下では薄い背景だけを加え、選択の下線を消しません。通常時は枠や背景で囲みません。

`Styles/UnderlineTabs.xaml` の `TabViewItem` テンプレートに表示を集約し、標準の `TabView` に選択、キーボード操作、アクセシビリティの役割を任せます。上段も内容に合わせた高さを確保し、固定高さによる下線のクリップを避けます。上段の装飾アイコンと件数表示はヘッダーに含めます。

合成データの画面テストで両方のタブを切り替え、ライト・ダーク各テーマで通常選択・ホバー・押下時の下線、文字の太さ、非選択側の下線消去、表示領域内に下線が収まることを検証します。

# 表示・比較するスキャン記録の選択

通常表示の「表示する記録」と比較の記録選択は共通のモーダルダイアログを使います。比較方式の選択は全モードで一番左です。比較なしではその右に「表示する記録」を置き、すべての比較モードでは同じ行に「基準の記録」→「比較する記録」を並べます。二重の枠による窮屈さを避け、背景と枠は日時ボタンだけに付けます。右側は通常表示の選択欄を兼ね、サイズ列は右側の記録の値です。期間指定時の左側は実際に自動選択された基準日時を表示する読み取り専用の欄です。手動選択には任意比較を使います。期間指定での自動表示と任意比較の選択値は分け、切り替えても手動の選択を保持します。差分の方向や符号の意味、指定された期間の詳細はツールチップで説明します。比較日時の別行での重複表示はなく、正常な比較の補足で行を増やしません。履歴不足や不確実な比較の説明は画面に残します。

最初は全記録を新しい順に表示します。日時を覚えていなくても「今日」「昨日」「年月」の区切りと、スキャン日時・記録数を手掛かりに一覧をスクロールできます。ページ切り替えは不要です。現在表示中の記録には「選択中」を付けます。

期間比較で使用できる記録が1件だけの場合は、その記録を「基準の記録」に表示し、「比較する記録」は「記録なし」とします。同じ記録を両端に置いて差分0とは扱いません。記録選択の内部状態は保持し、右側から別のスキャンを選ぶことも、比較なしへ戻すこともできます。

- 「すべて」「直近7日」「今月」「今年」で一覧を絞り込みます。直近7日は今日を含む7暦日です。
- 左側のカレンダーは補助的な日付絞り込みです。記録のある日に印を付け、選んだ日の一覧を表示します。「すべて」で日付の絞り込みを解除できます。日付は既存の表示と同じく、保存されたスキャン時のローカル日時を使います。
- 一覧で記録を選んでも表示中のスキャンは切り替わりません。ダイアログの「選択」で確定します。キャンセル・Escapeでは元の記録を保持します。候補が一覧にない場合は確定できません。
- 「選択」「キャンセル」は右下に並べ、最小幅96・高さ32・角丸4の標準ボタンスタイルを使います。SDKの標準テンプレートとキーボード操作を維持し、ボタン領域の等分伸張だけを解除します。
- 比較時はもう片方の日時もダイアログ内に表示します。同一記録や逆転した2点の選択は既存の比較検証で説明します。
- ドライブ変更や履歴更新では開いているダイアログを無効化して閉じます。古い記録の確定や、遅れて返った件数取得結果の反映を防ぎます。存在しなくなった選択を別の記録へ無断で差し替えません。
- 一覧はグループ化した仮想化ListViewです。記録数は表示される行のIDを最大64件ずつまとめてEF Core/LINQで取得し、各選択UIのメモリ上に保持します。更新時に削除済みIDを除去します。件数取得の失敗を0件として表示しません。監視処理やDBへのキャッシュ書き込みはありません。

ストレージのテストでは要求IDだけの件数取得、重複ID、不明ID、非公開化済み履歴、キャンセルを確認します。合成履歴のUI検証 `--demo --demo-history <専用ディレクトリ> --smoke-test <画像パス> --smoke-comparison --smoke-history-picker` は通常・比較表示に加え、全記録の初期表示、期間・日付による絞り込み、解除、空の範囲、記録数取得、未確定の閲覧を検証し、モーダルの画像を保存します。

日付の印にはWinUI標準の[CalendarView](https://learn.microsoft.com/en-us/windows/apps/develop/ui/controls/calendar-view)のdensity表示を利用します。

# サイズ差分モード

比較後のディスク上の割り当て容量から、比較前の容量を引く。正は増加、負は減少、既知のゼロ差は `±0 B`。フォルダ容量はサブフォルダ込み。通常表示と同じく可視名ごとに無名DATAを計上し、ハードリンクの各名前もそれぞれ比較する。ランキングの親子行は容量が重複するので、行の差分を足してドライブの増減としない。

## 期間と記録の選択

| 選択 | 要求する開始境界 |
| --- | --- |
| 24時間・7日間・30日間・365日間 | 現在時刻から指定した経過時間を引く |
| 今日 | PCのローカル日付の0時 |
| 今週 | ローカルの月曜日の0時 |
| 今月・今年 | ローカルの月初・年初の0時 |
| 任意の2スキャン | 保存済みの比較前・比較後を直接選択 |

自動期間は開始境界以前と現在時刻以前のそれぞれ最後の保存済み記録を選ぶ。境界後の記録で開始を代用しない。2つの異なる記録を選べなければ履歴不足。実際の比較日時は画面に表示する。夏時間で0時が存在しない場合は最初の有効な時刻、重複する場合は早い方の時刻を境界にする。任意選択では同じボリューム・時刻の順序を検証する。

直近24時間以前は既存の保持方針に従い1日最後の記録だけ残る。任意指定は残っている記録から選び、削除済みの時刻を復元・補間しない。比較用にスキャンや履歴のコピーを追加保存しない。比較中は通常の履歴選択を隠し、比較後の記録を閲覧対象にする。

## 一覧・ツリー・ランキング

一覧は現在のフォルダにある両記録の項目を合わせ、比較前・比較後・増減を表示する。増減の絶対値が大きい項目を先に置き、スクロール時には250件ずつ画面に追加する。同じフォルダ内で名前が変わった場合、世代を含むファイル参照が同じで対応が一意なら対にする。複数ハードリンクで対応が曖昧なら別行に残す。名前変更前の名前はツールチップで確認できる。

ツリーは両記録のフォルダを表示し、比較前だけにあるフォルダも保存済みの比較前から閲覧できる。ランキングは数値比較できるフォルダだけを増加順・減少順・絶対値順で表示し、深さ・最下位フォルダの条件を維持する。

片方にしか記録がない項目は「前の記録なし」「後の記録なし」。新規作成・削除の確定や0との引き算は行わない。容量未解決・名前集合未確定・帰属不明などで比較できない容量は数値差分にしない。フォルダの移動・名前変更はボリュームとMFT番号・世代番号で対応させる。フォルダ内のファイル移動は、移動元・先の一覧では片側の記録として表示する。世代番号が変わったMFT番号は別物。世代の周回などを含め、長期間の連続した同一性を保証するものではない。

## 実装と検証

既存DuckDB履歴と型付きLINQモデルを利用し、DBスキーマの追加・移行は不要。`ComparisonSelection` が期間・端点を決め、`ScanHistoryArchive.ReadFolderChanges` がフォルダ差分、`EntryChanges` が可視項目の対応と符号付き容量差を計算する。UIは読み取りをバックグラウンドで行い、比較選択の変更時は古い要求をキャンセルして世代を検証する。履歴の読み取り所有権は閲覧終了時に解放する。

フォルダ内の差分順を決めるには、そのフォルダ直下の両記録を先に読み取る。比較のたびに全ファイルをメモリへ展開する方式ではないが、非常に多くの直下項目を持つフォルダでは待ち時間・メモリ使用が増える。直近に比較した1フォルダだけ結果を再利用する。巨大な実機履歴での応答時間は別途確認が必要。

期間境界（夏時間を含む）、保持済み端点、履歴不足、異なるボリューム、選択順序、世代再利用、ハードリンク、名前変更、未解決、符号と容量の上限、キャンセルを自動テストで検証する。既存の合成データ用画面テストに `--smoke-comparison` を追加し、2記録の比較・子フォルダ移動・履歴不足・通常表示への復帰・古い要求のキャンセルを検証する。実ディスクや本物の履歴はテストで変更しない。

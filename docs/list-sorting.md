# 一覧の列ソート

ファイル、容量分析、DB管理の各一覧は列ヘッダーをボタンとして操作できます。選択列に ▲（昇順）・▼（降順）を表示します。再クリックで反転し、キーボードからも操作できます。名前列へ切り替えると昇順、数値・日時列へ切り替えると降順です。初期状態はファイル・容量分析がサイズ降順、DB管理が完了日時降順です。

- ファイル：名前・サイズ・比較時の増減。エクスプローラーと同様にフォルダを先頭のグループとして維持し、その中とファイルの中で並べ替えます。
- 容量分析：フルパス・サイズ・比較時の増減。深さ指定と並び順の選択欄を廃止し、最下位フォルダ条件は残します。
- DB管理：スキャン完了日時・記録数。並べ替えは削除対象の選択を変更しません。

表示済みの行だけをソートせず、全件を整列してから250件単位で追加します。容量や増減はUInt128/BigInteger等の元の数値で比較し、単位付き文字列では比較しません。不明値はどちらの方向でも末尾です。名前はUTF-16を復元した文字列をOrdinalIgnoreCaseで比較し、同順位はOrdinalとファイル参照等で安定化します。DB内のUTF-16バイト列をそのまま名前順として使いません。

通常のファイルサイズ順はDB側でソートしてからページを取り出します。各ページで同じ方向を指定し、スナップショット内のレコード・名前序数をタイブレークに使います。名前順は対象フォルダの全エントリを一時的に保持して文字列として整列し、その結果を追加表示します。差分も全比較結果を整列します。フォルダ内容の変更や次の並べ替えで古い追加読み込みは無効になります。DBスキーマの変更はありません。

比較解除時、増減列のソートはサイズ降順に戻します。表示されている他の列のソートは維持します。増減列の昇順・降順は、減少・不変・増加を含む並べ替えであり、増加／減少の絞り込みではありません。
